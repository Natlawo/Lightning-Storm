# ⚡ THE LIGHTNING SPHERE: APOCALYPSE ⚡

Sebuah game arked retro-cyberpunk hibrid yang dibina menggunakan **HTML5 Canvas** dan **Web Audio API** tanpa menggunakan sebarang gambar luaran (100% coding!).

## 📱 CARA MAIN
* **Laptop / PC:** Guna **Arrow Keys (Kiri/Kanan)** untuk gerak, tekan **Spacebar** untuk menembak.
* **Telefon Pintar (Mobile):** Sentuh sisi **Kiri / Kanan skrin** untuk bergerak dan menembak secara automatik.

## 🚀 TAHAP FASA
1. **LEVEL 1 (Score 0-90):** Mulai dengan 3 Nyawa. Tembakan tunggal. Musuh jatuh lurus.
2. **LEVEL 2 (Score 100-290):** Tembakan upgrade jadi **Twin Laser**. Musuh mula bergerak berombak!
3. **LEVEL 3 (Score 300+):** Nyawa dipotong 1. Tembakan maksimum **Triple Laser**. Musuh mengganas dan pandai menembak balik!
